# 截图裁剪与坐标换算维护，2026-10-08

本轮检查 read_region 的截图保真与坐标换算，未接管用户的应用。
三个确定性回归在修复前失败，修复后通过：

1. 指定 out_path 等于源截图时，原图会被覆盖。现在拒绝同路径、规范化路径别名和
   硬链接别名，输出须使用另一个文件，保留原始截图作为验收依据。
2. 完全越界或尺寸换算后为零的裁剪原先会被强行夹为边缘一像素，仍报告成功。
   现在报工具错误、不写输出；部分越界但仍与原图相交的区域继续裁剪到有效交集。
3. 7×5 像素按 1.5 放大实际得到 10×7，两个方向的比例分别为 10/7 和 7/5。
   原来的说明却都除以 1.5。现在新增 effective_scale=[sx,sy]，换算说明使用实际比例。

保留原有 upscale 字段，它记录请求比例。coordinate_convention=image_edges 表示
连续图像边界坐标：原图位置为 x0+mx/sx、y0+my/sy。像素中心/索引需要调用者按
其坐标约定换算；不能把请求比例与实际尺寸比混用。

图片处理的异常路径现在也关闭源图和裁剪图。默认输出仍为 *_crop，其他工具及
窗口输入行为未改动。26 项 Python 测试与 2 项 Node 包检查通过，新增回归只处理
临时图片，不点击、输入或截取用户窗口。本次没有重复上轮七项真实桌面验收。
